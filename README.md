# Orly Vlot

**Journey consultant · gezondheid · digitalisering · praktische AI**

Ik help organisaties hun dienstverlening te verbeteren vanuit de reis van de klant, cliënt of patiënt. Ik verbind journeydenken met gezondheid, digitalisering en automatisering: van inzicht in wat mensen nodig hebben naar praktische verbeteringen in hun dagelijks leven en werk.

Vanuit [Journey Consultancy](https://journeyconsultancy.nl/) werk ik aan consultancy, kennisplatforms en praktijknetwerken. Op GitHub laat ik zien wat ik bouw en deel ik de openbare onderdelen daarvan.
